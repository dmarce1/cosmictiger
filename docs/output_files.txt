COSMICTIGER OUTPUT INVENTORY (source audit, 2026-10-20)

Scope: every named output writer found in the current CosmicTiger simulation,
its built-in run.test diagnostics, and its shipped C++ conversion/export tools.
Silo products and checkpoint contents/directories/aliases are excluded. Python
analysis/campaign scripts and build/test infrastructure are outside this scope.
This inventories possible outputs, not files produced by every run or deleted
historical implementations. Source references use function names so changes to
copyright headers and terminal formatting do not invalidate them.

Location rules:
- Ordinary runtime names below are relative to output.directory. Default is ./output/<run.scenario>. outputPath creates parent directories. src/io/output.cpp (outputPath); src/core/options.cpp (processOptions).
- Built-in run.test mode bypasses output.directory for outputPath names, so they use the process working directory. Absolute paths stay absolute. src/io/output.cpp (outputPath).
- Lightcone names are relative to lightcone.directory, default output.directory + /lightcone. src/core/options.cpp (processOptions).
- stack_trace.txt defaults to the working directory before options are installed and in standalone utilities; setOptions changes it to outputPath("stack_trace.txt"). src/core/assert.cpp (stackTraceOutputPath / setStackTraceOutputPath); src/core/options.cpp (setOptions).
- N = output/coarse-step number; R = HPX rank; E = lightcone epoch.

SHIPPED TOOLS / EXCLUSIONS
- halo_catalog_export writes JSONL to stdout only (src/tools/halo_catalog_export.cpp (detail::exportSnapshot)); no fixed output filename. Shell redirection is caller-controlled.
- groups2halofunc writes mass-function columns to stdout only (src/tools/groups2halofunc.cpp (main)); no fixed output filename.
- healpix2silo writes only Silo (excluded).
- Anonymous tmpfile scratch storage is used in serialization/regression helpers (src/sph/sph_particles.cpp (sphCheckpointTest) src/io/checkpoint.cpp (checkpointStateTest) tests/compression.cpp). These are not named retained outputs.
- Build outputs, generated headers, compiler logs, CTest files, Python analysis/campaign reports, browser viewer exports, external HPX/CUDA/MPI profiling requested by environment, core dumps, and shell-redirection filenames are outside simulation-owned runtime output. They depend on the invoked tool and user-specified paths; not implicitly created by a normal cosmictiger run.
